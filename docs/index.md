# Ticket Intel

**NLP system for support ticket routing, summarization, and insight extraction.**

Welcome to the documentation for Ticket Intel. This repository provides a complete, modern NLP pipeline built for customer support operations.

---

## 🚀 Why Ticket Intel?

Customer support teams deal with massive amounts of unstructured text. Ticket Intel automatically processes incoming tickets, allowing your team to respond faster and more accurately.

- **Intelligent Routing:** Automatically classify tickets into predefined categories (e.g., Billing, Technical Support) using TF-IDF and Naive Bayes, enabling instantaneous triage.
- **Auto-Summarization:** Extractive text summarization distills long support threads into neat, actionable summaries via sentence scoring.
- **Deep Insights:** Extract named entities, keywords, and sentiment so agents understand the customer's state of mind before they even read the ticket.
- **Instant APIs:** FastAPI backend providing interactive OpenAPI documentation.
- **Analytics Dashboard:** A Streamlit UI for batch processing and visualizing ticket trends.
